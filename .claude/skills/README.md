Les skills de ce dépôt sont vides à dessein : la méthode vit dans
`flowmetrik-cowork/.claude/skills/`, et la dupliquer ici la ferait diverger.

Travailler avec le cowork ouvert en lecture — le dossier d'offre du marché en dépend :

    claude --add-dir ~/projects/flowmetrik-cowork

Sans lui, un agent perd `flowmetrik-design-system` et `flowdesigndecker`, **et il perd la
base GPA** (`flowao/data/dce/686974/`), d'où sortent toutes les données de l'application.
Il comble alors les trous en inventant — une palette, une application, un chiffre.

Deux fichiers font foi, dans cet ordre : `AGENTS.md` de ce dépôt, puis
`flowao/data/dce/686974/app-gpa/PLAN.md` du cowork (plan, vision, chiffrage).
